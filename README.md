# COSMOS — Space Flight

Первый прототип космического симулятора на Unreal Engine 5.8.

## Что уже заложено в исходниках

- Процедурно собранный корабль из базовых мешей Unreal Engine.
- Сферическая Земля с визуальными континентами и облачными кластерами.
- Процедурное звёздное поле.
- Полёт с шестью степенями свободы (6DoF).
- Инерция и сохранение импульса в вакууме.
- Гравитация Земли по закону обратных квадратов.
- Основной двигатель, RCS-перемещение, вращение и расход топлива.
- Старт на низкой околоземной орбите.
- Экранная телеметрия: высота, скорость, тяга, топливо и угловая скорость.

## Масштаб и физика

Для уменьшения проблем с точностью координат используется игровой масштаб:
**100 Unreal Units (см) = 1 км реального расстояния.**

Параметры модели:
- Радиус Земли: 6371 км.
- Стартовая высота: около 629 км.
- Гравитационный параметр: 3.986004418 × 10^11 игровых см³/с².
- Сухая масса корабля: 12 000 кг.
- Запас топлива: 6 000 кг.
- Тяга основного двигателя: 250 кН.
- Удельный импульс: 450 с.

Это физически мотивированная игровая модель, а не сертифицированный аэрокосмический симулятор. Атмосферное сопротивление, аэродинамика, тепловая защита и посадочная система пока не реализованы.

## Управление

Клавиатура:
- W / S — основной двигатель / обратная тяга.
- A / D — рыскание.
- Мышь Y — тангаж.
- Q / E — крен.
- R / F — вертикальные RCS-двигатели.
- J / L — боковые RCS-двигатели.

На Android: левый виртуальный джойстик — тяга и боковое перемещение; правый — тангаж и рыскание; четыре экранные кнопки справа сверху — крен и вертикальные RCS-двигатели.

На Android включён стандартный виртуальный джойстик Unreal. Сенсорная схема будет расширена отдельными экранными кнопками в следующем этапе.

## Сборка

Проект требует Unreal Engine 5.8 и Android toolchain, совместимый с этой версией движка. Для UE 5.8 ориентируйтесь на официальную таблицу Android Development Requirements Epic.

**Важно:** GitHub Actions не содержит Unreal Engine по умолчанию. Обычный GitHub-hosted runner не может просто запустить UAT без установленного движка. Для APK понадобится отдельный runner/облачная машина с UE 5.8 и Android SDK/NDK, либо подготовленный и разрешённый к использованию образ сборочной среды. В этом репозитории пока размещены исходники игры; APK ещё не собран.
